# AI Impact on Students - SQL Project

## Project Overview :

This project analyzes the impact of Artificial Intelligence (AI) usage on students academic behavior, skills, and dependency levels. Using SQL, the dataset is explored to identify patterns between AI usage, prompt engineering skills, tool diversity, study years, and dependency on AI tools. The project demonstrates SQL concepts such as filtering, aggregation, grouping, subqueries, CTEs, window functions, and data analysis techniques.

## Objectives :

- Analyze how frequently students use AI tools.
- Measure the relationship between AI usage and prompt engineering skills.
- Identify dependency levels on AI among students.
- Compare AI adoption across different study years.
- Explore tool diversity among students.
- Generate insights for responsible AI usage in education.

## Dataset Description :

|-------------------------------------------------------------|
|    Column Name   |            Description                   |
|------------------|------------------------------------------|
|  stu_id          | Unique identifier for each student       |
|  category        | Student category or classification       |
|  year_of_study   | Current academic year of the student     |
|  ai_hours        | Number of hours spent using AI tools     |
|  ai_use          | Frequency or level of AI usage           |
|  prompt_skill    | Student's prompt engineering skill level |
|  tool_diversity  | Number or variety of AI tools used       |
|  dependence      | Dependency level on AI tools             |
|-------------------------------------------------------------|
